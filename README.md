# corals-analytics
Package for quantitative analytics, data science and machine learning tasks.

The script imports data from .xlsx, .csv or .sav file into a dataframe. 
The tool covers simple tasks like distribution, mediation, moderation, correlation and linear regression, 
and also more advanced tasks like latent class analyses (clustering) and a variety of factor analyses. 
It also include a tool for creating new calculated variables.

Results can be displayed, exported in various visual or table formats, 
with the possibility to add them to a pptx-presentation. 

Important:
- Icon and image file must be kept in the same directory as the code file
- Powerpoint template must be kept in the same directory as the code file
- The Package PySimpleGui must be version 4.60.5.0 (Later versions are licenced)
